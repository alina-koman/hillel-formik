# Форма реєстрації

Навчальний проєкт — адаптивна форма реєстрації на React і TypeScript. Formik керує станом форми, Yup перевіряє введені дані, а Material UI забезпечує компоненти інтерфейсу, тему та базові стилі.

**Демо:** [hillel-formik.vercel.app](https://hillel-formik.vercel.app/)

## Можливості

- Ім’я, пароль та електронна пошта з підписами, підказками й автозаповненням.
- Перевірка обов’язкових полів, довжини імені (від 2 символів), довжини пароля (від 8 символів) і формату електронної пошти.
- Помилки валідації відображаються біля відповідних полів; після успішного надсилання форма очищується й показує повідомлення про успіх.
- Адаптивне оформлення: картка форми, градієнтний фон, Material UI TextField, кнопка та сповіщення.

> Форма демонструє клієнтську валідацію та обробку надсилання. Серверного API немає: значення форми виводяться в консоль браузера, дані не зберігаються та не передаються на сервер.

## Технології

- React 19, TypeScript і Vite
- Material UI та Emotion
- Formik і Yup
- Oxlint

## Локальний запуск

Потрібні Node.js і npm.

```bash
npm install
npm run dev
```

Після запуску Vite виведе адресу локального сервера в термінал.

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запустити сервер розробки |
| `npm run build` | Перевірити типи TypeScript і зібрати production-версію в `dist/` |
| `npm run preview` | Переглянути production-збірку локально |
| `npm run lint` | Запустити Oxlint |

## Структура проєкту

```text
src/
├── components/
│   ├── App.tsx             # Кореневий компонент
│   ├── BasicForm.tsx       # Formik-форма з компонентами Material UI
│   └── Input.tsx           # Поле Material UI, пов’язане з Formik
├── helpers/
│   └── validationSchema.ts # Yup-схема валідації
├── types/
│   └── FormValues.ts       # Тип значень форми
├── App.css                 # Стилі картки та форми
├── index.css               # Глобальні стилі
└── main.tsx                # Точка входу, тема Material UI та CssBaseline
```
